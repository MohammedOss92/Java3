سؤال مهم جدًا. هدفنا أن تصبح قادرًا على النظر إلى كود Java وتحديد Big O بنفسك، دون حفظ تعقيد كل خوارزمية.

سنستخدم طريقة ثابتة من 5 خطوات.

### 1\. حدّد ما هو n

عادةً `n` تعني حجم البيانات، مثل عدد عناصر المصفوفة:

```java
int[] numbers = {3, 5, 7, 9, 11};
```

هنا:

`n = numbers.length = 5`

### 2\. احسب تكرار الحلقة

مثلاً:

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}
```

* البداية: `i = 0`

* النهاية: `i = n`

* الزيادة: `i++`

إذن الحلقة تتكرر `n` مرة.

التعقيد: `O(n)`.

### 3\. افحص الحلقات المتداخلة

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i + " " + j);
    }
}
```

الحلقة الخارجية `n` مرة، والداخلية `n` مرة لكل دورة خارجية.

إذن:

n \\times n = n^2

التعقيد: `O(n²)`.

### 4\. انتبه إلى الحلقات المتتابعة

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

for (int j = 0; j < n; j++) {
    System.out.println(j);
}
```

الأولى `n` والثانية `n`.

n+n=2n

نحذف الثابت 2، فيصبح التعقيد `O(n)`.

### 5\. انتبه إلى طريقة زيادة المتغير

ليست كل الحلقات تستخدم `i++`.

مثلاً:

```java
int i = 1;

while (i < n) {
    i *= 2;
}
```

هنا تتضاعف قيمة `i`:

`1 → 2 → 4 → 8 → 16 → 32`

لذلك التعقيد `O(log n)`.

### الآن نطبّق معًا

أريدك أن تتعلم الحساب بنفسك، لذلك لن أعطيك الحل مباشرة.

انظر إلى هذا الكود:

```java
for (int i = 0; i < n; i++) {
    System.out.println(i);

    for (int j = 0; j < 3; j++) {
        System.out.println(j);
    }
}
```

السؤال الأول فقط:

كم مرة تتكرر الحلقة الخارجية إذا كان `n = 10`؟

لا تحسب التعقيد النهائي الآن؛ نحل خطوة خطوة.
