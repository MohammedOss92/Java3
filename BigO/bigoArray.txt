Java – فهم Space Complexity مع المصفوفات

1. ما المقصود بـ Space Complexity؟

هي مقدار الذاكرة الإضافية التي يحتاجها البرنامج أثناء التنفيذ.

نركز على:

عدد المتغيرات التي ننشئها.

حجم المصفوفات.

عدد المصفوفات التي ننشئها.

هل نحتفظ بالمصفوفات أم نستخدمها مؤقتًا؟

2. مصفوفة واحدة بحجم ثابت

int[] numbers = new int[5]; 

لدينا مصفوفة تحتوي على 5 عناصر.

الحجم ثابت، لا يتغير عندما تتغير قيمة n.

Space = O(1)

حتى لو كان الحجم 100 أو 1000، يظل ثابتًا ما دام لا يعتمد على n.

3. مصفوفة واحدة بحجم n

int[] numbers = new int[n]; 

إذا كانت n = 5، نحجز 5 عناصر.

إذا كانت n = 100، نحجز 100 عنصر.

إذن الذاكرة تزداد بزيادة n.

Space = O(n)

4. مصفوفات متعددة، كل واحدة حجمها ثابت

ArrayList<int[]> arrays = new ArrayList<>(); for (int i = 0; i < n; i++) { int[] temp = new int[5]; arrays.add(temp); } 

ماذا يحدث؟

الحلقة تنفذ n مرات.

في كل مرة ننشئ مصفوفة حجمها 5.

arrays.add(temp) يحتفظ بالمصفوفة داخل القائمة.

إجمالي العناصر:

5 × n = 5n

نحذف الثابت 5 عند حساب Big O.

Space = O(n)

5. مصفوفات متعددة، كل واحدة حجمها n

ArrayList<int[]> arrays = new ArrayList<>(); for (int i = 0; i < n; i++) { int[] temp = new int[n]; arrays.add(temp); } 

ماذا يحدث؟

الحلقة تنفذ n مرات.

في كل مرة ننشئ مصفوفة حجمها n.

نحتفظ بكل المصفوفات داخل القائمة.

إجمالي العناصر:

n × n = n²

Space = O(n²)

6. مصفوفة مؤقتة لا نحتفظ بها

for (int i = 0; i < n; i++) { int[] temp = new int[n]; temp[0] = i; } 

ماذا يحدث؟

ننشئ مصفوفة حجمها n.

نستخدمها في الدورة الحالية.

لا نضيفها إلى قائمة أو نخزن مراجعها في مكان آخر.

لا نحتفظ بالمصفوفات السابقة.

أقصى مساحة للمصفوفة المؤقتة الحية في الوقت نفسه هي n عناصر.

Space = O(n)

ملاحظة: إنشاء المصفوفة في كل دورة لا يعني جمع مساحة كل النسخ السابقة؛ نحن نحسب الذاكرة الحية المطلوبة في الوقت نفسه.

7. جدول المقارنة

الحالةSpaceمتغير واحدO(1)مصفوفة حجمها 5O(1)مصفوفة حجمها nO(n)n مصفوفات، كل واحدة حجمها 5، ونحتفظ بهاO(n)n مصفوفات، كل واحدة حجمها n، ونحتفظ بهاO(n²)مصفوفة مؤقتة حجمها nO(n)3 مصفوفات، كل واحدة حجمها nO(n) 

8. القاعدة المهمة

عندما تحسب Space للمصفوفات، اسأل نفسك:

كم مصفوفة أنشأت؟

ما حجم كل مصفوفة؟

هل أحتفظ بها كلها أم أستخدمها مؤقتًا؟

ما أكبر مقدار من الذاكرة يكون حيًا في الوقت نفسه؟

تذكّر:

الحجم الثابت = O(1).

الحجم الذي يعتمد على n = O(n).

عدد n من المصفوفات، وكل واحدة حجمها n، مع الاحتفاظ بها = O(n²).

لا تحفظ النتائج فقط؛ افهم كيف وصلت إلى عدد العناصر في الذاكرة.
