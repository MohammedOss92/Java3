Java – تحليل Time Complexity وSpace Complexity للمصفوفات

1. الفرق بين Time وSpace

النوعماذا نقيس؟Time Complexityعدد العمليات التي ينفذها البرنامج مع زيادة حجم nSpace Complexityمقدار الذاكرة الإضافية التي يحتاجها البرنامج مع زيادة n 

مثال:

int[] numbers = new int[n]; int sum = 0; for (int i = 0; i < n; i++) { sum += numbers[i]; } 

Time = O(n): الحلقة تتكرر n مرة.

Space = O(n): المصفوفة حجمها n.

2. إنشاء مصفوفة واحدة

int[] numbers = new int[n]; 

عدد المصفوفات: 1.

حجم المصفوفة: n.

Space = O(n).

حتى لو لم تستخدم المصفوفة، فإن إنشاءها يحجز الذاكرة لها.

3. إنشاء عدة مصفوفات بأحجام متغيرة ولكن عددها ثابت

int[] a = new int[n]; int[] b = new int[n]; int[] c = new int[n]; 

المساحة:

n + n + n = 3n

Space = O(n).

السبب: عدد المصفوفات ثابت، وهو 3.

حتى لو أنشأت 100 مصفوفة، يبقى Space = O(n)، ما دام عددها ثابتًا.

4. إنشاء مصفوفات داخل Loop والاحتفاظ بها

نستخدم ArrayList للاحتفاظ بالمصفوفات التي أنشأناها:

ArrayList<int[]> arrays = new ArrayList<>(); for (int i = 0; i < n; i++) { int[] temp = new int[n]; arrays.add(temp); } 

ماذا يحدث؟

الحلقة تتكرر n مرة.

في كل دورة ننشئ مصفوفة جديدة بحجم n.

نضيف المصفوفة إلى ArrayList.

لا نحذف المصفوفات السابقة، بل نحتفظ بها جميعًا.

إذا كانت n = 4:

الدورةحجم المصفوفةمجموع العناصر14424834124416 

إجمالي المساحة:

n × n = n²

Time = O(n²) تقريبًا: إنشاء n مصفوفات، وكل واحدة فيها n عناصر تُهيّأ.

Space = O(n²): نحتفظ بكل المصفوفات.

ملاحظة: الإضافة إلى ArrayList في هذه الحالة تكلف O(1) في المتوسط لكل عملية.

5. عدد المصفوفات n وحجم كل مصفوفة ثابت

ArrayList<int[]> arrays = new ArrayList<>(); for (int i = 0; i < n; i++) { int[] temp = new int[10]; arrays.add(temp); } 

عدد المصفوفات = n.

حجم كل مصفوفة = 10.

إجمالي العناصر = 10n.

إذن:

Time = O(n).

Space = O(n).

لأن 10 ثابت ولا نعتبره عامل نمو.

6. عدد المصفوفات n وأحجامها تتغير

ArrayList<int[]> arrays = new ArrayList<>(); for (int i = 0; i < n; i++) { int[] temp = new int[i + 1]; arrays.add(temp); } 

إذا كانت n = 5:

الدورةiحجم المصفوفة101212323434545 

إجمالي العناصر:

1 + 2 + 3 + 4 + 5 = 15

وبشكل عام:

1 + 2 + ... + n = n(n+1)/2

إذن:

Time = O(n²) تقريبًا بسبب تهيئة المصفوفات.

Space = O(n²) بسبب الاحتفاظ بكل المصفوفات.

7. إنشاء مصفوفة داخل Loop دون الاحتفاظ بالمصفوفات السابقة

for (int i = 0; i < n; i++) { int[] temp = new int[n]; // استخدام المصفوفة } 

هنا لا نضيف المصفوفات إلى قائمة أو بنية أخرى.

في تحليل الذاكرة الحية القصوى، إذا لم تبقَ المصفوفات السابقة قابلة للوصول، فإن مساحة المصفوفة المؤقتة تكون O(n)، وليس O(n²).

Time = O(n²) تقريبًا بسبب إنشاء n مصفوفات، كل واحدة بحجم n.

Space = O(n) للذاكرة الإضافية الحية في كل دورة.

ملاحظة: وقت تحرير الذاكرة الفعلي يعتمد على Garbage Collector في Java، لكن هذا لا يغير تحليل المساحة الحية القصوى في هذا المثال.

9. القواعد التي يجب أن تتذكرها

Time: انظر إلى عدد العمليات والتكرارات.

Space: انظر إلى الذاكرة الإضافية التي يحتاجها البرنامج.

إنشاء مصفوفة بحجم n يعني O(n) مساحة.

عدد ثابت من المصفوفات بحجم n يعني O(n).

n مصفوفات، حجم كل واحدة n، مع الاحتفاظ بها يعني O(n²).

إذا كانت أحجام المصفوفات تتغير، اجمع أحجامها كلها.

وجود حلقتين متداخلتين لا يعني تلقائيًا O(n²)؛ افحص عدد التكرارات الفعلي.

لا تخلط بين عدد المتغيرات وحجم البيانات التي تخزنها.

هل أحتفظ بكل المصفوفات السابقة، أم أستخدم مصفوفة مؤقتة واحدة فقط؟
