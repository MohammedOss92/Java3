المقصود أن تتعلم كيف تحسب عدد العناصر الموجودة في الذاكرة بنفسك، بدلًا من حفظ أن هذا الكود يساوي `O(n)` أو ذاك يساوي `O(n²)`.

دعنا نطبّقها خطوة خطوة.

### المثال الأول: n مصفوفات، كل واحدة حجمها 5

```java
ArrayList<int[]> arrays = new ArrayList<>();

for (int i = 0; i < n; i++) {
    int[] temp = new int[5];
    arrays.add(temp);
}
```

لنفترض أن `n = 3`.

أنشأنا 3 مصفوفات:

ما الذي يوجد في الذاكرة؟

المصفوفة 1

1

2

3

4

5

المصفوفة 2

1

2

3

4

5

المصفوفة 3

1

2

3

4

5

المجموع: 3 × 5 = 15 عنصرًا

الآن نرجع إلى `n` بدلًا من 3:

* لدينا n مصفوفات.

* كل مصفوفة فيها 5 عناصر.

* المجموع `5n`.

* نحذف الثابت 5 عند حساب Big O.

إذن `O(n)`.

### المثال الثاني: n مصفوفات، كل واحدة حجمها n

```java
ArrayList<int[]> arrays = new ArrayList<>();

for (int i = 0; i < n; i++) {
    int[] temp = new int[n];
    arrays.add(temp);
}
```

لنفترض أن `n = 3`.

ما الذي يوجد في الذاكرة؟

المصفوفة 1

1

2

3

المصفوفة 2

1

2

3

المصفوفة 3

1

2

3

المجموع: 3 × 3 = 9 عناصر

وعندما تكون `n`:

* لدينا n مصفوفات.

* كل مصفوفة فيها n عناصر.

* المجموع `n × n = n²`.

إذن `O(n²)`.

### الطريقة التي أريدك أن تستخدمها مع أي كود

اسأل نفسك سؤالين:

* كم عنصرًا أحجز في المرة الواحدة؟

* كم مرة أحتفظ بهذا الحجز؟

ثم اضرب العددين، وبعدها بسّط الناتج باستخدام Big O.

### الآن دورك

لدينا هذا الكود:

```java
for (int i = 0; i < n; i++) {
    int[] temp = new int[4];
    arrays.add(temp);
}
```

السؤال الأول فقط: إذا كانت `n = 5`، كم مصفوفة أنشأنا؟
