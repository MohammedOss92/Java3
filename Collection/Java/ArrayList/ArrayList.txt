سنبدأ بتجميع دوال ArrayList في Java وList في Python وList / MutableList في Kotlin في مرجع واحد، مع توضيح وظيفة كل دالة ومقابلها في اللغات الثلاث.

ملاحظة مهمة:

* Java: `ArrayList`

* Python: `list`

* Kotlin: `List` للقراءة فقط، و`MutableList` للإضافة والحذف والتعديل.

### 1\. إنشاء القائمة

| العملية         | Java                               | Python                   | Kotlin                  |
| --------------- | ---------------------------------- | ------------------------ | ----------------------- |
| إنشاء فارغة     | new ArrayList<>()                  | []                       | mutableListOf<Int>()    |
| إنشاء بقيم      | new ArrayList<>(List.of(10,20,30)) | [10,20,30]               | mutableListOf(10,20,30) |
| قائمة قراءة فقط | لا يوجد مقابل مباشر                | لا يوجد ضمان للقراءة فقط | listOf(10,20,30)        |
| عدد العناصر     | size()                             | len(numbers)             | size                    |
| فحص الفراغ      | isEmpty()                          | not numbers              | isEmpty()               |

### 2\. إضافة العناصر Add

| الوظيفة            | Java           | Python              | Kotlin         |
| ------------------ | -------------- | ------------------- | -------------- |
| إضافة عنصر         | add(40)        | append(40)          | add(40)        |
| إضافة في موقع      | add(1,40)      | insert(1,40)        | add(1,40)      |
| إضافة مجموعة       | addAll(list)   | extend(list)        | addAll(list)   |
| إضافة مجموعة بموقع | addAll(1,list) | numbers[1:1] = list | addAll(1,list) |

مثال:

```java
ArrayList<Integer> numbers = new ArrayList<>();

numbers.add(10);
numbers.add(20);
numbers.add(30);

numbers.add(1, 15);
```

النتيجة:

```text
[10, 15, 20, 30]
```

### 3\. الوصول إلى العناصر Get

| الوظيفة          | Java           | Python         | Kotlin        |
| ---------------- | -------------- | -------------- | ------------- |
| الوصول لعنصر     | get(0)         | numbers[0]     | numbers[0]    |
| أول عنصر         | get(0)         | numbers[0]     | first()       |
| آخر عنصر         | get(size()-1)  | numbers[-1]    | last()        |
| أول عنصر أو null | لا يوجد مباشرة | لا يوجد مباشرة | firstOrNull() |
| آخر عنصر أو null | لا يوجد مباشرة | لا يوجد مباشرة | lastOrNull()  |

مثال:

```java
System.out.println(numbers.get(0));
```

```python

```

```kotlin

```

| حذف آخر عنصر     | remove(size()-1)            | pop()               | removeAt(lastIndex)     |

### 13\. مثال عملي موحد باللغات الثلاث

لدينا القائمة:

```text
10, 20, 30, 40, 50
```

نريد:

* إضافة 60.

* الوصول إلى العنصر الأول.

* تعديل العنصر الثاني إلى 100.

* حذف 30.

* البحث عن 40.

* ترتيب القائمة.

* حساب المجموع.

* إيجاد أكبر وأصغر عنصر.

Java

```java
ArrayList<Integer> numbers =
    new ArrayList<>(List.of(10,20,30,40,50));

numbers.add(60);

System.out.println(numbers.get(0));

numbers.set(1, 100);

numbers.remove(Integer.valueOf(30));

System.out.println(numbers.contains(40));

Collections.sort(numbers);

System.out.println(numbers.stream()
    .mapToInt(Integer::intValue).sum());

System.out.println(Collections.max(numbers));
System.out.println(Collections.min(numbers));
```

Python

```python
numbers = [10, 20, 30, 40, 50]

numbers.append(60)

print(numbers[0])

numbers[1] = 100

numbers.remove(30)

print(40 in numbers)

numbers.sort()

print(sum(numbers))

print(max(numbers))
print(min(numbers))
```

Kotlin

```kotlin
val numbers = mutableListOf(10, 20, 30, 40, 50)

numbers.add(60)

println(numbers[0])

numbers[1] = 100

numbers.remove(30)

println(numbers.contains(40))

numbers.sort()

println(numbers.sum())

println(numbers.maxOrNull())
println(numbers.minOrNull())
```

### 14\. الفرق الذي يجب أن تحفظه في Kotlin

| List                             | MutableList     |
| -------------------------------- | --------------- |
| قراءة العناصر                    | قراءة العناصر   |
| لا تسمح بالتعديل من خلال الواجهة | تسمح بالتعديل   |
| listOf()                         | mutableListOf() |
| size                             | size            |
| get()                            | get()           |
| contains()                       | contains()      |
| لا يوجد add()                    | add()           |
| لا يوجد remove()                 | remove()        |
| لا يوجد set()                    | set()           |

مهم: `List` لا تعني بالضرورة أن البيانات غير قابلة للتغيير من أي مكان؛ بل تعني أنك لا تستطيع تعديلها من خلال مرجع `List` نفسه.
