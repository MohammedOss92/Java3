سنبدأ بجميع أنواع Array و ArrayList في Kotlin من الصفر إلى المستوى الذي تحتاجه في حل مسائل الخوارزميات والمقابلات.

سأرتبها لك حسب الموضوع، مع الدوال (Functions) والأمثلة. وسنطبق عملياً خطوة بخطوة.

### 1\. Array في Kotlin

المصفوفة ذات الحجم الثابت.

```kotlin
fun main() {

    // إنشاء مصفوفة أعداد صحيحة
    val numbers = arrayOf(10, 20, 30, 40)

    // الوصول إلى العناصر
    println(numbers[0])

    // تعديل عنصر
    numbers[0] = 100

    // عدد العناصر
    println(numbers.size)

    // المرور على العناصر
    for (num in numbers) {
        println(num)
    }
}
```

### أنواع إنشاء Array

| النوع            | الاستخدام    |
| ---------------- | ------------ |
| arrayOf()        | مصفوفة عامة  |
| intArrayOf()     | أعداد صحيحة  |
| doubleArrayOf()  | أعداد عشرية  |
| floatArrayOf()   | Float        |
| longArrayOf()    | Long         |
| booleanArrayOf() | Boolean      |
| charArrayOf()    | Char         |
| byteArrayOf()    | Byte         |
| shortArrayOf()   | Short        |
| emptyArray()     | مصفوفة فارغة |

مثال:

```kotlin
val a = intArrayOf(10, 20, 30)
val b = doubleArrayOf(1.5, 2.5)
val c = booleanArrayOf(true, false)
val d = charArrayOf('A', 'B', 'C')
val e = arrayOf("Ali", "Omar", "Ahmad")
```

### 3\. ArrayList في Kotlin

تسمح بإضافة وحذف العناصر وتغيير حجم القائمة.

```kotlin
fun main() {

    val numbers = ArrayList<Int>()

    numbers.add(10)
    numbers.add(20)
    numbers.add(30)

    println(numbers)
}
```

ويمكن كتابتها أيضاً:

```kotlin
val numbers = arrayListOf(10, 20, 30)
```

ملاحظة: بعض هذه الدوال تأتي من مكتبة Kotlin القياسية وتعمل على ArrayList لأنها تطبق واجهة List أو MutableList.

### 5\. أنواع List في Kotlin

| النوع           | قابل للتعديل؟ |
| --------------- | ------------- |
| List            | لا            |
| MutableList     | نعم           |
| ArrayList       | نعم           |
| arrayListOf()   | نعم           |
| listOf()        | لا            |
| mutableListOf() | نعم           |

مثال:

```kotlin
val a: List<Int> = listOf(10, 20, 30)

val b: MutableList<Int> = mutableListOf(10, 20, 30)

val c: ArrayList<Int> = arrayListOf(10, 20, 30)
```

### 6\. الفرق بين Array و ArrayList

| المقارنة       | Array     | ArrayList |
| -------------- | --------- | --------- |
| الحجم          | ثابت      | متغير     |
| إضافة عنصر     | لا مباشرة | نعم       |
| حذف عنصر       | لا مباشرة | نعم       |
| تعديل عنصر     | نعم       | نعم       |
| الوصول بالفهرس | نعم       | نعم       |
| التكرار        | ممكن      | ممكن      |
| الاستخدام      | حجم معروف | حجم متغير |

### 7\. أهم العمليات التي يجب أن تتدرب عليها

هذه ليست مجرد دوال؛ بل مسائل مهمة في الخوارزميات:

* طباعة جميع العناصر.

* إيجاد أكبر وأصغر عنصر.

* حساب المجموع والمتوسط.

* عكس المصفوفة.

* البحث الخطي Linear Search.

* البحث الثنائي Binary Search.

* حذف التكرارات.

* عد تكرار كل عنصر.

* إيجاد العنصر الثاني الأكبر.

* دمج مصفوفتين.

* ترتيب تصاعدي وتنازلي.

* نقل الأصفار إلى النهاية.

* إيجاد العناصر المشتركة.

* إيجاد العناصر غير المشتركة.

* تدوير المصفوفة يميناً ويساراً.
