هنا أنت تتحدث عن Bubble Sort، وليس Selection Sort.

لاحظ الفرق بين الحلقتين:

```java
for (int i = 0; i < num.length - 1; i++) {

    for (int j = 0; j < num.length - 1; j++) {

        if (num[j] > num[j + 1]) {
            int temp = num[j];
            num[j] = num[j + 1];
            num[j + 1] = temp;
        }
    }
}
```

### لماذا الاثنتان تبدأان من 0؟

الحلقة الأولى i:

* تمثل عدد دورات الترتيب.

* نحتاج إلى `length - 1` دورة كحد أقصى.

الحلقة الثانية j:

* تبدأ من 0 لأننا نقارن العنصر الأول بالذي يليه.

* `j = 0` يقارن الفهرس 0 مع الفهرس 1.

* `j = 1` يقارن الفهرس 1 مع الفهرس 2.

* وهكذا.

### لماذا الشرط j أقل من length - 1؟

لأننا نستخدم:

```java
num[j + 1]
```

فلا نريد أن يتجاوز الفهرس الأخير.

### الفرق المهم بين Bubble و Selection

| الخوارزمية     | بداية الحلقة الداخلية |
| -------------- | --------------------- |
| Bubble Sort    | j = 0                 |
| Selection Sort | j = i + 1             |

سؤال لك:

في Bubble Sort، لماذا لا نبدأ الحلقة الداخلية من `j = i + 1` مثل Selection Sort؟

فكر في طريقة المقارنة: هل نقارن العنصر بالذي يليه أم نبحث عن أصغر عنصر في بقية المصفوفة؟


في Bubble Sort:

* الحلقة الخارجية `i`: تحدد رقم الدورة.

* الحلقة الداخلية `j`: تمثل فهرس العنصر الحالي الذي نفحصه.

* `j + 1`: يمثل فهرس العنصر الذي يليه.

مثلاً:

```java
for (int i = 0; i < num.length - 1; i++) {

    for (int j = 0; j < num.length - 1; j++) {

        if (num[j] > num[j + 1]) {
            // تبديل
        }
    }
}
```

لاحظ:

| التعبير | معناه            |
| ------- | ---------------- |
| i       | رقم الدورة       |
| j       | العنصر الحالي    |
| j + 1   | العنصر الذي يليه |

انتبه لنقطة مهمة:

الحلقة `j` هي التي تتحرك بين العناصر وتقارنها، أما `i` فلا يمثل العنصر الحالي في المقارنة، بل يمثل الدورة الخارجية.
