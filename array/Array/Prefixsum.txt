سنراجع درس Prefix Sum في Java كاملًا من البداية إلى النهاية، بطريقة مرتبة، مع شرح كل سطر ومثال عملي.

### 1\. ما هو Prefix Sum؟

Prefix Sum يعني المجموع التراكمي.

أي أن كل عنصر في مصفوفة `prefix` يحتوي مجموع العناصر من بداية المصفوفة `numbers` حتى موقعه الحالي.

مثال:

```java
int[] numbers = {4, 3, 2, 6, 5};
```

ننشئ مصفوفة Prefix:

```java
int[] prefix = {4, 7, 9, 15, 20};
```

كيف حصلنا على هذه القيم؟

| Index | numbers | عملية الجمع       | prefix |
| ----- | ------- | ----------------- | ------ |
| 0     | 4       | 4                 | 4      |
| 1     | 3       | 4 + 3             | 7      |
| 2     | 2       | 4 + 3 + 2         | 9      |
| 3     | 6       | 4 + 3 + 2 + 6     | 15     |
| 4     | 5       | 4 + 3 + 2 + 6 + 5 | 20     |

لاحظ أن كل خانة في `prefix` تحتوي مجموع العناصر السابقة مع العنصر الحالي.

### 2\. لماذا نستخدم Prefix Sum؟

لنفترض أنك تريد حساب مجموع عناصر من المصفوفة.

مثلاً:

```java
int[] numbers = {4, 3, 2, 6, 5};
```

تريد جمع العناصر من `index 1` إلى `index 3`.

أي:

```java
3 + 2 + 6 = 11
```

يمكنك جمعها باستخدام حلقة `for`، لكن إذا أردت حساب مجموع نطاقات كثيرة، ستحتاج إلى تكرار الجمع في كل مرة.

هنا تأتي فائدة Prefix Sum: نحسب المجموع التراكمي مرة واحدة، وبعدها نحسب مجموع أي نطاق بعملية طرح واحدة.

### 3\. فهم left و right

هذان المتغيران يمثلان مواقع العناصر (Indexes)، وليس قيم الأرقام.

لدينا:

```java
int[] numbers = {4, 3, 2, 6, 5};
```

| Index | 0   | 1   | 2   | 3   | 4   |
| ----- | --- | --- | --- | --- | --- |
| Value | 4   | 3   | 2   | 6   | 5   |

* `left`: موقع بداية الجزء الذي نريد جمعه.

* `right`: موقع نهاية الجزء الذي نريد جمعه.

مثال:

نريد جمع `3 + 2 + 6`.

```java
int left = 1;
int right = 3;
```

مثال آخر:

نريد جمع `2 + 6 + 5`.

```java
int left = 2;
int right = 4;
```

تذكّر أن `left` و`right` يحددان النطاق المطلوب.

### 4\. قانون Prefix Sum

### sum = prefix\[right\] - prefix\[left - 1\]

القانون الأساسي لحساب مجموع نطاق معين

لماذا نستخدم الطرح؟

لدينا:

```java
numbers = {4, 3, 2, 6, 5};
prefix  = {4, 7, 9, 15, 20};
```

نريد جمع العناصر من `index 1` إلى `index 3`.

أي:

```java
3 + 2 + 6 = 11
```

نعوض:

```java
int left = 1;
int right = 3;

int sum = prefix[right] - prefix[left - 1];
```

الآن نفصل العملية:

```java
sum = prefix[3] - prefix[1 - 1];

sum = prefix[3] - prefix[0];

sum = 15 - 4;

sum = 11;
```

لماذا طرحنا `prefix[0]`؟

لأن `prefix[3]` يحتوي مجموع المصفوفة من البداية حتى index 3:

```text
4 + 3 + 2 + 6 = 15
```

لكننا لا نريد الرقم `4` الموجود قبل بداية النطاق.

لذلك نطرح `4`:

```text
15 - 4 = 11
```

وهكذا حصلنا على مجموع العناصر المطلوبة.

### 5\. ماذا لو كان left = 0؟

هذه حالة خاصة ومهمة.

مثلاً نريد جمع العناصر من `index 0` إلى `index 2`.

```java
int left = 0;
int right = 2;
```

نريد:

```text
4 + 3 + 2 = 9
```

هنا لا نستطيع تطبيق القانون السابق مباشرة؛ لأنه سيحاول الوصول إلى:

```java
prefix[-1]
```

وهذا Index غير موجود.

لذلك نستخدم شرطًا:

```java
int sum;

if (left == 0) {
    sum = prefix[right];
} else {
    sum = prefix[right] - prefix[left - 1];
}
```

معناه:

* إذا بدأ الجمع من أول عنصر، نأخذ `prefix[right]` مباشرة.

* إذا بدأ من أي موقع آخر، نستخدم قانون الطرح.

### 6\. كيف نبني مصفوفة Prefix باستخدام for؟

بدل كتابة قيم `prefix` يدويًا، نريد أن ينشئها البرنامج تلقائيًا.

الكود:

```java
int[] numbers = {4, 3, 2, 6, 5};

int[] prefix = new int[numbers.length];

// أول عنصر في prefix يساوي أول عنصر في numbers
prefix[0] = numbers[0];

// نبدأ من index 1
for (int i = 1; i < numbers.length; i++) {

    prefix[i] = prefix[i - 1] + numbers[i];

}
```

شرح أهم سطر:

```java
prefix[i] = prefix[i - 1] + numbers[i];
```

يعني:

* `prefix[i - 1]`: المجموع التراكمي السابق.

* `numbers[i]`: العنصر الحالي.

* `prefix[i]`: نخزن فيه المجموع الجديد.

مثلاً عندما `i = 2`:

```java
prefix[2] = prefix[1] + numbers[2];

prefix[2] = 7 + 2;

prefix[2] = 9;
```

وعندما `i = 3`:

```java
prefix[3] = prefix[2] + numbers[3];

prefix[3] = 9 + 6;

prefix[3] = 15;
```

### 7\. البرنامج الكامل

هذا البرنامج يجمع كل ما تعلمناه:

* إنشاء مصفوفة `numbers`.

* إنشاء مصفوفة `prefix`.

* بناء Prefix Sum باستخدام `for`.

* تحديد `left` و`right`.

* حساب مجموع النطاق.

* طباعة الناتج.

```java

public class PrefixSum {

    public static void main(String[] args) {

        // المصفوفة الأصلية
        int[] numbers = {4, 3, 2, 6, 5};

        // إنشاء مصفوفة Prefix بنفس الحجم
        int[] prefix = new int[numbers.length];

        // أول عنصر
        prefix[0] = numbers[0];

        // بناء المجموع التراكمي
        for (int i = 1; i < numbers.length; i++) {

            prefix[i] = prefix[i - 1] + numbers[i];

        }

        // تحديد بداية ونهاية النطاق
        int left = 1;
        int right = 3;

        // حساب مجموع النطاق
        int sum;

        if (left == 0) {

            sum = prefix[right];

        } else {

            sum = prefix[right] - prefix[left - 1];

        }

        // طباعة النتيجة
        System.out.println("Sum = " + sum);

    }
}
```

الناتج النهائي

```text
Sum = 11
```

### 8\. Time Complexity و Space Complexity

| العملية                         | التعقيد |
| ------------------------------- | ------- |
| إنشاء Prefix                    | O(n)    |
| حساب مجموع نطاق واحد بعد البناء | O(1)    |
| مساحة مصفوفة Prefix الإضافية    | O(n)    |

لماذا حساب مجموع النطاق `O(1)`؟

لأننا نستخدم عمليتي وصول إلى المصفوفة وعملية طرح، ولا نحتاج إلى حلقة تمر على العناصر.

### 9\. الفرق بين Prefix Sum و Sliding Window

| المقارنة         | Prefix Sum                 | Sliding Window            |
| ---------------- | -------------------------- | ------------------------- |
| الفكرة           | مجموع تراكمي               | نافذة تتحرك               |
| الاستخدام        | حساب مجموع نطاقات كثيرة    | البحث عن نافذة تحقق شرطًا |
| الوقت            | بناء O(n)، والاستعلام O(1) | غالبًا O(n)               |
| المساحة الإضافية | O(n)                       | غالبًا O(1)               |

### 10\. اختبار فهمك

لن ننتقل إلى موضوع جديد قبل التأكد من فهم Prefix Sum.

اختبار Prefix Sum

0 / 4

السؤال 1: لدينا numbers = {2, 4, 3, 1}. ما قيمة prefix\[2\]؟

6

9

10

4

السؤال 2: إذا كان left = 2 و right = 3، فما العناصر التي نريد جمعها؟

2 + 4

3 + 1

3 + 1 بعد تحديد index

4 + 3

السؤال 3: إذا كان left = 0، كيف نحسب المجموع؟

prefix\[right\]

prefix\[right\] - prefix\[left\]

prefix\[left - 1\]

numbers.length

السؤال 4: ما تعقيد حساب مجموع نطاق واحد بعد بناء prefix؟

O(n)

O(n²)

O(1)

O(log n)
