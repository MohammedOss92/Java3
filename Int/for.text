نعم. خلينا نفرّق بينهم بطريقة **تفكير حل المسألة**، وليس فقط شكل الكود.

## 1. `for` العادية

نستخدمها عندما نحتاج **رقم/Index العنصر** أو نريد التحكم في البداية والنهاية والخطوة.

```java
for (int i = 0; i < words.length; i++) {
    System.out.println(words[i]);
}
```

هنا عندنا `i`:

```text
i = 0 → words[0]
i = 1 → words[1]
i = 2 → words[2]
i = 3 → words[3]
```

### استخدم `for` عندما تحتاج:

* رقم العنصر `index`
* الوصول إلى عنصر قبله أو بعده
* تغيير عناصر الـ Array
* زيادة/نقصان بأكثر من 1
* التحكم الدقيق في بداية ونهاية الحلقة

مثلاً:

```java
for (int i = 0; i < arr.length; i++) {
    arr[i] = arr[i] * 2;
}
```

# 2. `for-each`

نستخدمها عندما نريد **العناصر نفسها** واحدًا واحدًا، ولا نهتم بالـ index.

```java
for (String word : words) {
    System.out.println(word);
}
```

اقرأها:

> لكل `word` موجودة داخل `words`

مثلاً:

```text
words = ["I", "love", "Java", "programming"]

word = "I"
word = "love"
word = "Java"
word = "programming"
```

### استخدم `for-each` عندما:

* تريد قراءة العناصر
* حساب المجموع
* البحث عن عنصر
* معرفة أطول كلمة
* معرفة عدد العناصر التي تحقق شرطًا
* لا تحتاج إلى `index`

مثلاً أطول كلمة:

```java
String longest = "";

for (String word : words) {
    if (word.length() > longest.length()) {
        longest = word;
    }
}
```

هنا لا يهمني هل الكلمة رقم 0 أو 1 أو 2.

يهمني فقط:

> ما هي الكلمة الحالية؟

---

# 3. Nested `for`

`Nested` يعني:

> **حلقة داخل حلقة**

مثال:

```java
for (int i = 0; i < 3; i++) {

    for (int j = 0; j < 3; j++) {

        System.out.println(i + " " + j);
    }
}
```

الفكرة:

```text
i = 0
   j = 0
   j = 1
   j = 2

i = 1
   j = 0
   j = 1
   j = 2

i = 2
   j = 0
   j = 1
   j = 2
```

أي أن الحلقة الداخلية تعمل **كاملة** لكل دورة من الحلقة الخارجية.

---

# متى نستخدم Nested؟

عندما تكون المشكلة تحتاج إلى مقارنة أو التعامل مع **كل عنصر مع عناصر أخرى**.

مثلاً:

### البحث عن الحروف المكررة

```java
String text = "hello";

for (int i = 0; i < text.length(); i++) {

    for (int j = i + 1; j < text.length(); j++) {

        if (text.charAt(i) == text.charAt(j)) {
            System.out.println(text.charAt(i));
        }
    }
}
```

لأننا نريد:

```text
h ← يقارن مع باقي الحروف
e ← يقارن مع باقي الحروف
l ← يقارن مع باقي الحروف
l ← يقارن مع باقي الحروف
o
```

هنا نحتاج **مقارنة عنصر بعنصر آخر**، لذلك Nested مناسب.

# الفرق بسرعة

| النوع        | متى أستخدمه؟                                      |
| ------------ | ------------------------------------------------- |
| `for`        | أحتاج `index` أو تحكمًا بالعداد                   |
| `for-each`   | أريد العناصر واحدًا واحدًا فقط                    |
| `nested for` | أحتاج حلقة داخل حلقة، غالبًا للمقارنة بين العناصر |

### احفظها بهذه الطريقة:

**هل أحتاج رقم العنصر؟**

➡️ نعم → `for`

**لا أحتاج رقم العنصر، فقط أريد كل عنصر؟**

➡️ `for-each`

**أحتاج أن أقارن كل عنصر بعناصر أخرى أو أتعامل مع مستويين؟**

➡️ `nested for`

---

### مثال واحد يوضح الثلاثة

```java
String[] words = {"Java", "Python", "Kotlin"};
```

**طباعة مع index:**

```java
for (int i = 0; i < words.length; i++) {
    System.out.println(i + " " + words[i]);
}
```

**طباعة بدون index:**

```java
for (String word : words) {
    System.out.println(word);
}
```

**مقارنة كل كلمة مع كل كلمة:**

```java
for (int i = 0; i < words.length; i++) {

    for (int j = i + 1; j < words.length; j++) {

        System.out.println(words[i] + " - " + words[j]);
    }
}
```

**قاعدة مهمة جدًا لك في الـ Problem Solving:**

> لا تبدأ بالسؤال: "أي `for` أستخدم؟"
> ابدأ بالسؤال: **"ماذا أريد أن أفعل في كل دورة؟"**

ثم تختار نوع الحلقة.
