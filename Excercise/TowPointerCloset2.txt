شرح خوارزمية Two Pointer Sum Closest في Java

1. فكرة المسألة

لدينا مصفوفة مرتبة تصاعديًا، ونريد إيجاد جميع الأزواج التي يكون مجموعها أقرب ما يمكن إلى قيمة target.

int[] numbers = {2, 4, 6, 8, 10}; int target = 13; 

في هذا المثال، أقرب مجموعين إلى الهدف 13 هما 12 و14، والفرق في الحالتين يساوي 1.

2. المؤشران

int left = 0; int right = numbers.length - 1; 

left: يبدأ عند أول عنصر.

right: يبدأ عند آخر عنصر.

نستخدم المؤشرين لتكوين زوج من عنصرين، ثم نحسب مجموعهما.

3. أفضل فرق وأفضل النتائج

int bestDiff = Integer.MAX_VALUE; int[] bestLeft = new int[numbers.length]; int[] bestRight = new int[numbers.length]; int[] bestSums = new int[numbers.length]; int count = 0; 

bestDiff: يحتفظ بأصغر فرق وجدناه حتى الآن.

bestLeft: يخزن العنصر الأيسر لكل زوج.

bestRight: يخزن العنصر الأيمن لكل زوج.

bestSums: يخزن مجموع كل زوج.

count: يحدد عدد الأزواج المحفوظة والفهرس التالي المستخدم للتخزين.

استخدمنا ثلاث مصفوفات عادية بدلًا من Collections، لأننا نريد الاحتفاظ بعناصر كل زوج ومجموعه.

4. حساب المجموع والفرق

int sum = numbers[left] + numbers[right]; int diff = Math.abs(sum - target); 

sum: مجموع العنصرين الحاليين.

diff: الفرق المطلق بين المجموع والهدف.

نستخدم Math.abs() للحصول على فرق موجب، سواء كان المجموع أكبر من الهدف أو أصغر منه.

مثال:

12 والهدف 13: الفرق 1.

14 والهدف 13: الفرق 1.

5. تحديث أفضل فرق

if (diff < bestDiff) { bestDiff = diff; count = 0; } 

إذا وجدنا فرقًا أصغر من أفضل فرق سابق:

نحدّث bestDiff.

نعيد count إلى صفر، لأن النتائج السابقة لم تعد تحقق أفضل فرق.

لا نمسح محتويات المصفوفات فعليًا؛ بل نتجاهل النتائج القديمة ونبدأ الكتابة من الفهرس صفر.

6. حفظ الزوج عندما يحقق أفضل فرق

if (diff == bestDiff) { bestLeft[count] = numbers[left]; bestRight[count] = numbers[right]; bestSums[count] = sum; count++; } 

إذا كان الفرق الحالي مساويًا لأفضل فرق، نحفظ:

العنصر الأيسر.

العنصر الأيمن.

مجموعهما.

ثم نزيد count للانتقال إلى الخانة التالية.

استخدمنا شرطين منفصلين لأن الزوج الذي يحقق فرقًا جديدًا أصغر يجب أن يُحفظ أيضًا بعد تحديث bestDiff.

7. تحريك المؤشرين

if (sum == target) { break; } else if (sum < target) { left++; } else { right--; } 

إذا كان المجموع مساويًا للهدف، نتوقف؛ لأن الفرق صفر.

إذا كان المجموع أصغر من الهدف، نحرك left إلى اليمين لزيادة المجموع المحتمل.

إذا كان المجموع أكبر من الهدف، نحرك right إلى اليسار لتقليل المجموع المحتمل.

تعتمد هذه الطريقة على أن المصفوفة مرتبة تصاعديًا.

8. طباعة النتائج

System.out.println("Best Difference = " + bestDiff); for (int i = 0; i < count; i++) { System.out.println( bestLeft[i] + " + " + bestRight[i] + " = " + bestSums[i] + ", Difference = " + Math.abs(bestSums[i] - target) ); } 

نطبع أفضل فرق، ثم نمر على النتائج المحفوظة من الفهرس صفر حتى count - 1، ونطبع كل زوج ومجموعه والفرق عن الهدف.

9. النتيجة في مثالنا

Best Difference = 1 Best pairs: 2 + 10 = 12, Difference = 1 4 + 10 = 14, Difference = 1 4 + 8 = 12, Difference = 1 6 + 8 = 14, Difference = 1

ملاحظة مهمة: هذه الطريقة تفحص الأزواج التي يصل إليها أسلوب المؤشرين في المصفوفة المرتبة، وتحتفظ بأفضل النتائج التي يعثر عليها. وهي لا تفحص كل الأزواج الممكنة بالضرورة. إذا وصلنا إلى مجموع يساوي الهدف، نتوقف لأن الفرق صفر، ولذلك لا توجد حاجة إلى البحث عن فرق أصغر.
