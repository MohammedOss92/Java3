شرح Two Pointers — نقل الأصفار إلى نهاية المصفوفة في Java

1. المطلوب من المسألة

لدينا المصفوفة:

int[] numbers = {0, 3, 0, 5, 7};

نريد نقل جميع الأصفار إلى النهاية، مع الحفاظ على ترتيب الأرقام غير الصفرية.

النتيجة المطلوبة:

{3, 5, 7, 0, 0}

2. الفكرة الأساسية

نستخدم مؤشرين، ولكل مؤشر وظيفة مختلفة:

أولًا: وظيفة i

"i" هو مؤشر البحث.

- يمر على عناصر المصفوفة من البداية إلى النهاية.
- يفحص كل عنصر.
- إذا وجد صفرًا، يتجاوزه.
- إذا وجد رقمًا غير صفري، نضع هذا الرقم في المكان الذي يشير إليه "left".

إذن: i يبحث عن الرقم غير الصفري التالي.

ثانيًا: وظيفة left

"left" هو مؤشر المكان.

- يحدد المكان الذي يجب وضع الرقم غير الصفري التالي فيه.
- يبدأ من الفهرس "0".
- عندما نضع رقمًا غير صفري في مكانه، نزيد "left" بمقدار واحد.
- لا نزيده عندما يكون العنصر الذي يفحصه "i" صفرًا.

إذن: left يحدد أين نضع الرقم الذي وجده i.

الفرق باختصار

المؤشر| وظيفته
"i"| يبحث ويفحص عناصر المصفوفة
"left"| يحدد مكان وضع الرقم غير الصفري
"temp"| يحفظ قيمة مؤقتة أثناء التبديل

3. لماذا نحتاج إلى temp؟

عند تبديل قيمتين، نحتاج إلى حفظ إحداهما مؤقتًا حتى لا نفقدها.

int temp = numbers[left];
numbers[left] = numbers[i];
numbers[i] = temp;

ترتيب العمل:

1. نحفظ قيمة "numbers[left]" داخل "temp".
2. ننقل قيمة "numbers[i]" إلى مكان "left".
3. نضع القيمة المحفوظة في "temp" داخل مكان "i".

4. شرح الكود من البداية

int[] numbers = {0, 3, 0, 5, 7};

int left = 0;

for (int i = 0; i < numbers.length; i++) {

    if (numbers[i] != 0) {

        int temp = numbers[left];
        numbers[left] = numbers[i];
        numbers[i] = temp;

        left++;
    }
}

السطر الأول

int[] numbers = {0, 3, 0, 5, 7};

إنشاء المصفوفة التي نريد تعديلها.

السطر الثاني

int left = 0;

نبدأ من الفهرس "0"؛ لأنه أول مكان نريد وضع رقم غير صفري فيه.

الحلقة

for (int i = 0; i < numbers.length; i++)

يجعل "i" يمر على كل عنصر في المصفوفة.

الشرط

if (numbers[i] != 0)

إذا كان العنصر الذي وصل إليه "i" غير صفري، ننفذ التبديل.

التبديل

int temp = numbers[left];
numbers[left] = numbers[i];
numbers[i] = temp;

نضع الرقم غير الصفري في المكان الذي يشير إليه "left"، وننقل القيمة القديمة إلى مكان "i".

زيادة left

left++;

بعد وضع الرقم غير الصفري، ننتقل إلى المكان التالي.

5. تتبع المصفوفة خطوة خطوة

المصفوفة في البداية:

"{0, 3, 0, 5, 7}"

قيمة i| العنصر| ماذا يحدث؟| قيمة left بعد الخطوة| المصفوفة
0| 0| نتجاوز الصفر| 0| "{0, 3, 0, 5, 7}"
1| 3| نبدّل مع العنصر عند left| 1| "{3, 0, 0, 5, 7}"
2| 0| نتجاوز الصفر| 1| "{3, 0, 0, 5, 7}"
3| 5| نبدّل مع العنصر عند left| 2| "{3, 5, 0, 0, 7}"
4| 7| نبدّل مع العنصر عند left| 3| "{3, 5, 7, 0, 0}"

النتيجة النهائية:

"{3, 5, 7, 0, 0}"

6. ملاحظات مهمة

- "i" يتحرك في كل دورة من الحلقة.
- "left" يتحرك فقط عندما نجد رقمًا غير صفري.
- قد يكون "i" و"left" متساويين؛ وهذا طبيعي، والتبديل مع العنصر نفسه لا يسبب مشكلة.
- لا نحتاج إلى حلقة داخل حلقة؛ لأننا نستطيع نقل الأرقام غير الصفرية بمؤشرين.
- لا نحتاج إلى "continue"؛ لأن الشرط يكفي لتحديد متى ننفذ التبديل.

7. كيف أفكر في مسائل مشابهة؟

عندما ترى مسألة تستخدم مؤشرين، اسأل نفسك:

1. ماذا يفعل المؤشر الأول؟
2. ماذا يفعل المؤشر الثاني؟
3. متى يتحرك كل مؤشر؟
4. ما الشرط الذي يجعلني أغيّر المصفوفة؟

الخلاصة التي يجب فهمها:

"i" يبحث عن الرقم، و"left" يحدد مكان وضعه.
